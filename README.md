# TaskFlow

A full-stack task manager web application where users can add, complete, delete, and filter tasks.

## Live Demo
https://shivam-thakur142.github.io/task-manager/

## Features
- Add new tasks
- Mark tasks as completed
- Filter tasks: All, Pending, and Completed
- Delete tasks
- Tasks stay saved after refresh

## Built With
- HTML
- CSS
- JavaScript
- Node.js
- Express
- MongoDB Atlas
- Render

## How It Works
The frontend is hosted on GitHub Pages. It sends requests to a Node.js and Express backend hosted on Render. The backend stores tasks permanently in MongoDB Atlas.
